# Slime Novels

Leitor pessoal instalável para celular. Permite carregar EPUB, PDF, DOCX e TXT no próprio navegador. Os arquivos ficam no IndexedDB deste dispositivo e não são enviados ao repositório.

## Publicação
Ative GitHub Pages para servir os arquivos estáticos pela branch `main`, pasta `/ (root)`. Para instalar no Android, abra o endereço publicado no Chrome e use **Instalar app** ou **Adicionar à tela inicial**.

## Leitura
Use **Adicionar novels** e selecione um ou vários arquivos. EPUB é exibido capítulo por capítulo; PDF abre no leitor do navegador; DOCX e TXT aparecem em uma página de leitura.

Observação: o leitor usa JSZip e Mammoth via CDN para abrir EPUB e DOCX; esses formatos exigem conexão na primeira carga das bibliotecas.
